# タカネ式 JFT-Basic 対策サイト Vol.1

紙のPDF（194ページ）と同じ 210問が入った学習サイトです。
サーバー側の処理もビルド作業もありません。このフォルダをそのまま公開すれば動きます。

```
jft-site/
├ index.html        本体（これ1枚に全部入っています）
├ manifest.json     ホーム画面に追加するための設定
├ sw.js             オフラインで使うための仕組み
├ icons/            ホーム画面に出るアイコン
└ audio/            聴解の mp3 を入れる場所（今は空）
```

---

## 1. 公開して URL をつくる

友だちに送るには、まず URL が必要です。**いちばん速いのは Netlify Drop** です。

### A. Netlify Drop（5分・無料）

1. <https://app.netlify.com/drop> を開く
2. `jft-site` フォルダを**ドラッグ＆ドロップ**する
3. `https://xxxx-yyyy.netlify.app` という URL がすぐ出る
4. サイト名は後から好きな名前に変えられる

### B. GitHub Pages（TAKUMI と同じやり方・無料）

```bash
cd jft-site
git init
git add .
git commit -m "JFT-Basic Vol.1"
git branch -M main
git remote add origin git@github.com:<あなた>/<リポジトリ>.git
git push -u origin main
```

**Settings → Pages → Source: main / (root)** を選んで保存。
数分で `https://<あなた>.github.io/<リポジトリ>/` で見られるようになります。

### C. Cloudflare Pages

管理画面で「Upload assets」を選び、フォルダをドロップするだけ。独自ドメインも無料で付けられます。

> **Google Drive は使えません。** Drive はウェブサイトの公開機能を終了しているので、
> HTML を置いてもページとしては開けません（mp3 の置き場所としては使えます）。

---

## 2. 友だちに配る

公開できたら、サイトを開いて右上の **「共有」** ボタンを押してください。

- **QRコード** が出ます。教室ならこれを見せるだけで全員がスマホで開けます
- **「リンクを送る」** で WhatsApp などにそのまま送れます
- **「リンクをコピー」** でメッセージに貼り付けられます

---

## 3. スマホでアプリのように使ってもらう

友だちには、開いたあとに**ブラウザのメニューから「ホーム画面に追加」**を選ぶよう伝えてください。

- Android（Chrome）：右上の「⋮」→「アプリをインストール」または「ホーム画面に追加」
- iPhone（Safari）：下の共有ボタン → 「ホーム画面に追加」

追加すると、アイコンから全画面で開くようになり、**一度開いたあとは電波がなくても使えます**。
スリランカの通信事情を考えると、ここまで案内してあげると使われ方がかなり変わります。

---

## 4. 聴解の音声

`audio/` フォルダに Camb.AI で作った mp3 を入れてください。

```
JFT1_P3_Q01.mp3 … JFT1_P3_Q36.mp3   練習問題 第3部
JFT1_MK_Q26.mp3 … JFT1_MK_Q37.mp3   模擬試験
```

ファイル名はサイト側・紙のPDF側と**1文字も違わず**一致させること。
mp3 が無い問題は、自動でその端末の読み上げ機能（Web Speech API）に切り替わります。

mp3 を別の場所（Cloudflare R2 / S3 など）に置く場合は、URL の後ろに付けるだけで差し替えられます。

```
https://<あなたのサイト>/?audio=https://cdn.example.com/jft1/
```

---

## 5. 中身を差し替えたとき

`index.html` を新しいものに置き換えたら、`sw.js` の1行目あたりにある

```js
var CACHE = "jft1-v1";
```

の数字を `jft1-v2` のように上げてください。上げないと、すでに開いたことがある人の端末に
古い版が残り続けます。

---

## 6. 知っておいてほしいこと

- 生徒の解答は**ブラウザを閉じると消えます**。サーバーには何も送っていません。
  学習履歴を残したい場合は、ログインのあるアプリ側で扱ってください。
- **模擬試験の答えは HTML の中にあります。** 本気の実力測定に使うときは、
  教室で先生が見ている場でやらせてください。
- シンハラ語の訳は機械翻訳ではありませんが、ネイティブの確認は一度通してください。
